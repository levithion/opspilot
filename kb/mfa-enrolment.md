# Multi-factor authentication (MFA)

## Enrolling
Every account must use Microsoft Authenticator. Go to aka.ms/mfasetup, sign in and follow the prompts to add the Authenticator app. New starters are asked to enrol on their first day.

## New phone
Before wiping the old phone, open Authenticator and enable cloud backup. On the new phone, restore from backup. If the old phone is already gone, use the lost phone procedure below.

## Lost phone or no MFA access
Report the lost device to it-security immediately. IT can issue a Temporary Access Pass, a one-time code that is valid for 8 hours so you can register a new Authenticator. IT must verify your identity first, usually with a video call with your manager. Issuing a Temporary Access Pass or resetting MFA is an approval-gated action.

## Number matching
Sign-in prompts show a two-digit number that you must type into Authenticator. If you receive a prompt you did not trigger, deny it and report it as a security incident.
